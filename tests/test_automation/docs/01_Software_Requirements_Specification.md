## 1 Intended use

Nodeon is a desktop editor for plain-text structure trees (for example a project folder structure or a topic map). It lets the user build, fold, restructure, explain and colour-mark tree branches while the file stays a pure UTF-8 .txt file.

## 2 Conventions

* Every requirement has a permanent id `REQ-<AREA>-<NNN>`; ids are never re-used.
* *shall* = mandatory. Each requirement is one testable statement with an acceptance criterion.
* Priority: High = core function / data integrity, Medium = important convenience, Low = cosmetic.
